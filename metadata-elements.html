Current editor field registry

Metadata elements and Stata crosswalk

A complete reference for the fields currently available in the editor. Each row connects the form label to the DDI-Codebook 2.6 output and, where applicable, the intended Stata representation.

How to read this page. Paths omit the outer codeBook element for clarity. An asterisk marks a field that the current editor requires.

The Stata column uses the ODF–DDI Stata application profile where a direct mapping exists. “Companion metadata” means that Stata has no native, one-to-one field; the information should remain in DDI XML or be retained as a dataset/variable note or characteristic.

Maintenance reference

This registry mirrors the fields in index.html. When a field is added, renamed, or removed from the editor, update the corresponding table in the same change.
